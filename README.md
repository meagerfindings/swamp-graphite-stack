# swamp-graphite-stack

[swamp](https://swamp.club) extension `@mgreten/graphite-stack` — composition
lifecycle for a Graphite (`gt`) multi-PR stack: validate, finalize, restack,
compose, and submit ordered draft PRs.

📖 **Extension documentation:** [extensions/models/README.md](extensions/models/README.md)

📦 **Install:** `swamp extension pull @mgreten/graphite-stack`

## Repository layout

This repository is a swamp workspace (its own `.swamp.yaml` repo). The
publishable extension lives under [extensions/models/](extensions/models/).
